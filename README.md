## 🚀 Projetos em destaque

### 🌱 [Arujé — Plataforma de Monitoramento Agrícola Inteligente](https://github.com/gugomesx10/ARUJE)
API back-end em **.NET 8** que simula uma plataforma de monitoramento agrícola com sensores IoT, mensageria assíncrona e um assistente de IA (RAG).

- Clean Architecture, Entity Framework Core e **PostgreSQL**
- Processamento assíncrono com **RabbitMQ**, Outbox Pattern, Worker Service e Dead Letter Queue
- Assistente virtual com **RAG + Gemini**, classificador de intenção e histórico de conversa
- Observabilidade com **Prometheus** e **Grafana**, autenticação JWT, testes automatizados e CI/CD com GitHub Actions
- Integração IoT simulada com ESP32/Wokwi

`.NET 8` `PostgreSQL` `RabbitMQ` `Docker` `RAG` `Gemini API` `Prometheus/Grafana`

### 🐾 [PetOS — API REST para Gestão de Pets](https://github.com/gugomesx10/PetOS-Java)
API REST em **Java 17 / Spring Boot 3** para gestão de saúde, vacinas, rotinas e alertas de pets.

- Arquitetura em camadas (controller, service, repository, DTO, mapper)
- Geração automática de alertas de vacinas vencidas/próximas do vencimento
- Documentação com **Swagger/OpenAPI** e cache com Spring Cache
- Testado com H2 Database para desenvolvimento ágil

`Java 17` `Spring Boot 3` `Spring Data JPA` `Swagger/OpenAPI` `H2 Database`
